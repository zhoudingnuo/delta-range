# DELTA RANGE

一个用原生 HTML5 Canvas 写成的第一人称射击 / 练枪游戏，按《三角洲行动》靶场素材复刻场景、HUD 和武器，并加入干员机动技能与波次生存玩法。整个游戏是**单文件**（`index.html`），枪声与换弹音频已内嵌，双击即玩，无需联网或安装依赖。

在线游玩：<https://zhoudingnuo.github.io/delta-range/>

## 模式

| 模式 | 说明 |
| --- | --- |
| 静止靶场 | 60 秒，4 个静止靶，练精准点射 |
| 移动靶 | 60 秒，4 个轨道横移靶；喷气与滑铲无冷却 |
| 极限速射 | 45 秒，4 个近距小靶，练压枪 |
| 实战演练 | 波次生存：敌人会推进、找位、还击；共 10 波，清完即撤离成功，阵亡则结束 |

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `Shift` | 冲刺 |
| `Ctrl` | 战术滑铲（行进中）/ 蹲下 |
| `Space` | 跳跃 / 滑铲跳 |
| 鼠标左键 | 射击 / 挥刀 |
| 鼠标右键（单击） | 开镜 / 收起（无框玻璃瞄具） |
| 鼠标侧键 / `Q` | 动力推进（八方向喷气） |
| `G` | 投掷破片手雷（2 枚） |
| `F` | 投掷烟雾弹（2 枚） |
| `1` | 切回 M250 轻机枪 |
| `3` | 切战术匕首 |
| `R` | 换弹 |
| `B` | 单发 / 全自动 |
| `H` | 显示 / 隐藏数据面板 |
| `Esc` | 暂停 |

## 干员机制

- **红狼 · 战术滑铲**：冲刺中按 `Ctrl` 触发，滑铲期间仍可开火；结束后有短暂冷却，冷却中再滑只能出短铲。
- **威龙 · 动力推进**：朝输入方向八向喷气，空中可变向；喷气与后摇期间枪会收起，无法开火。
- **取消后摇**：按 `3` 切刀、再按 `1` 切枪，可以立即取消动力推进的后摇。
- 击倒敌人会让动力推进的冷却减半。

## 实战演练

- 靶子全部是 **3D 实体人形**（有厚度、面向玩家、倒下时绕底座翻转），命中判定按头/胸/肩/手臂/骨盆/腿分部位计算。
- 敌人会从远端两条靶道推进，停在 9–17 米处还击；红色装甲、红色目镜与靶场的训练假人区分。
- 受击会掉血，屏幕出现受击方向弧线和低血量红边；6 秒未受伤开始缓慢回血。
- 敌人倒下有概率掉落**医疗包**（+28 生命），走近自动拾取。
- 每清完一波有 3 秒喘息并回复少量生命，波次越高敌人越多、血量越厚、射速越快。
- 第 3 波起会出现**重装敌人**：体型更大、血量约 2.2 倍、伤害更高。
- **破片手雷 / 烟雾弹**：破片对 5 米内敌人造成范围伤害；烟雾持续约 9 秒，站在烟里能显著降低敌人命中率。
- 清完第 10 波判定「撤离成功」；阵亡则记录抵达波数。历史最高波数保存在本地。

## 特色

- 自研 Canvas 2D 伪 3D 渲染：透视投影、面排序、雾、灯光与体积感武器。
- 靶场始终保持 4 个存活靶，击倒后约 0.05–0.1 秒补靶；菜单可调靶子血量（50–500）。
- 后坐力默认是原版的 2 倍，菜单提供 0.5×–4× 倍率滑条。
- 鼠标灵敏度基准下调到原来的 0.6×，菜单滑条可继续调。
- 移动靶会周期性使用「动力推进」和「滑铲」加速变向（带蓝色尾迹/滑铲压身）。
- 视角不限制左右旋转（可 360° 转身），俯仰放宽到约 ±86°；身后补了带后门的封闭墙面。
- 真实采样枪声 / 换弹声（来自素材视频）内嵌为 base64，本地 `file://` 也能播放。
- 完整 HUD：伤害统计、命中率、爆头率、弹药、血量、波次、击杀提示、喷气冷却。
- 移动系统带碰撞、镜头晃动、滑铲压镜、喷气速度线与视野变化。

## 运行

直接双击 `index.html`。如果浏览器限制了本地指针锁定，可以在目录里起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```
